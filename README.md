# Проект: Сбор данных о книгах
Проект создан для демонстрации базовых приёмов web scraping на Python:
извлечения данных с HTML-страниц, автоматизации регулярных запусков и тестирования кода.

### Основные задачи:

- парсинг информации о книгах с сайта Books to Scrape;

- сбор данных по всем страницам каталога;

- сохранение результатов в файл books_data.txt;

- настройка ежедневного автоматического запуска с помощью schedule;

- покрытие ключевых функций автотестами через pytest.


### Инструкции по запуску:

1. Клонируйте репозиторий:  
   `git clone https://github.com/0x39f963/novikov_dz3`  
2. Установите зависимости:  
   `pip install -r requirements.txt`  
3. Запустите сбор данных:  
   `python scraper.py`  
   — результат будет сохранён в `artifacts/books_data.txt`  
4. Запустите тесты:  
   `pytest -q`
